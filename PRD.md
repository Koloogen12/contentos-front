## 1. СУТЬ ПРОДУКТА

ContentOS — облачный сервис для создания контента для соцсетей с помощью ИИ
на **визуальном узловом канвасе**. Пользователь превращает любой исходный
материал — видео, подкаст, статью, аудиофайл или идею — в готовые публикации
под каждую платформу, в собственном голосе, не выходя из одного окна.

**Ключевой сдвиг:**
- **До:** источник в папке → копируешь в ChatGPT → копируешь обратно →
  черновик в заметках → руками адаптируешь под каждую соцсеть → публикуешь
  вручную → метрики нигде.
- **С ContentOS:** всё на одной доске. Тянешь связь `Источник → Извлечение →
  Формат` — и пайплайн запущен. Текст звучит как ты, публикация в один клик.

**Базовый флоу:**
```
[Источник] ──→ [Извлечение] ──→ [Формат] ──→ публикация
 видео/подкаст   ИИ вытащил      ИИ написал     Telegram / LinkedIn
 статья/аудио    тезисы          пост под        напрямую или копией
 /идея           со скором       платформу
```

**Кому:** фаундеры, эксперты, консультанты и авторы, у которых есть материал
и мысли, но нет времени регулярно превращать их в контент.

## 2. АРХИТЕКТУРА ПРОДУКТА — узловой канвас

Бесконечное полотно (React Flow). Пользователь ставит ноды и соединяет их в
пайплайн. Каждая нода запускается отдельно, ветками или целиком («Запустить
всё»). Статусы ноды: idle / running / done / error.

### 2.1 Ноды-источники
- **Текст** — вставить пост/статью/транскрипт вручную.
- **URL** — ссылка на статью/блог, сервер вытаскивает чистый текст.
- **YouTube** — ссылка на видео/подкаст → транскрипт (субтитры или Whisper).
- **Файл** — загрузка аудио/видео (mp3/mp4/m4a/wav/…) → транскрипция.
- **Drag-and-drop** — файл можно бросить прямо на канвас, нода создаётся сама.

### 2.2 Ноды-трансформации
- **Извлечение идей** — из источника 15–40 «молекулярных тезисов», каждый
  оценён по 4 осям виральности (попадание в аудиторию, крючок, уникальность,
  соответствие автору) и привязан к контент-столбу.
- **Саммари** — плотное краткое изложение источника.
- **Сюжетная арка** — из большой темы многопостовая нарративная арка
  (TOFU/MOFU/BOFU).

### 2.3 Ноды-форматы (готовый контент под платформу)
- **Telegram** — пост с HTML-разметкой (жирный, курсив, спойлеры, цитаты).
- **LinkedIn** — структурированный пост с хэштегами.
- **Instagram / Reels** — сценарий рилс с таймингом.
- **X / Twitter** — тред/пост.
- **Карусель** — 6–10 слайдов, рендерятся в готовые JPEG-картинки (ИИ-обложка
  + вёрстка).
- **Хуки** — банк заголовков-крючков.
- **Статья** — лонгрид 1500–2500 слов для блога.

### 2.4 LLM-нода (AI-ассистент на канвасе)
- Чат с моделью Claude Opus 4.8 прямо на полотне.
- В неё **подключаются любые ноды** (источники, тезисы, готовые посты) — их
  содержимое становится контекстом разговора.
- **Своя инструкция (роль/задача)** на каждую ноду: одна нода — критик, другая
  — генератор хуков, третья — фактчекер.
- **Выход**: последний ответ ассистента можно подать дальше в `Извлечение` /
  `Формат` / другую `LLM-ноду` — обсудил идею в чате и толкнул её в конвейер.

## 3. СЛОИ ИНТЕЛЛЕКТА

### 3.1 Голос автора (Voice Training)
Система обучается на прошлых текстах пользователя. Импорт из публичного
Telegram-канала, YouTube-канала, ссылок на блог или вставкой вручную. Образцы
индексируются (pgvector), и на каждой генерации ИИ получает few-shot примеры —
текст звучит как автор, а не как обезличенный ИИ.

### 3.2 Бренд-контекст
Профиль автора: имя, био, активные продукты, правила голоса, характерные
слова, тон, табу (о чём никогда не писать), манифест (убеждения), CTA-слова,
столбы контента. Всё это подмешивается в каждый AI-вызов.

### 3.3 База знаний
Тезисы, референсы, аудитория, темы — с оценкой виральности, тегами и
статусом «спящий» (высокий скор, давно не использован).

### 3.4 Контент-план
Недельный календарь. Расписание постов, статусы (черновик → готов →
запланирован → опубликован). Виджет «Что писать сегодня» — рекомендации на
основе спящих тезисов и баланса контент-столбов.

## 4. ПУБЛИКАЦИЯ И МЕТРИКИ
- **Telegram** — прямая публикация. Общий бот добавляется админом в канал
  пользователя; проверка доступа перед сохранением адресата.
- **LinkedIn** — подключение аккаунтов.
- **Метрики** — сбор просмотров/реакций из Telegram, привязка к постам.
- **Публичный просмотр канваса** по токен-ссылке, шаблоны пайплайнов.

## 5. ЖИЗНЕННЫЙ ЦИКЛ ПОЛЬЗОВАТЕЛЯ (тарифы/доступ)
```
Аноним (preview)  →  Регистрация  →  Trial 24ч  →  Free / платный
 1 канвас,            обязательна    без лимитов    (Solo/Pro/Team —
```

  плейсхолдер, оплата через Т-Банк в разработке (Phase 2).

## 6. ТЕХНОЛОГИИ
- **Frontend:** Next.js 15 (App Router), TypeScript, Tailwind, React Flow,
  Zustand, TanStack Query.
- **Backend:** FastAPI (async), SQLAlchemy 2.0, PostgreSQL + pgvector, Redis +
  Arq (очередь/воркер), Playwright (рендер каруселей).
- **ИИ:** Claude Opus 4.8 через прокси CometAPI. Whisper для транскрипции.
- **Инфраструктура:** Docker на Selectel, S3-хранилище, JWT-авторизация,
  мультитенантность (организации).

## 7. ЛЕНДИНГ — БРИФ ДЛЯ CLAUDE DESIGN

> Сейчас публичной посадочной страницы нет: `/try` авто-создаёт preview и
> кидает на `/dashboard`, поэтому весь продукт по факту спрятан за входом.
> Задача — собрать нормальный публичный лендинг. Ниже — вводные под сборку.

**Позиционирование (заголовок):**
«Контент-конвейер для серьёзных авторов.»
Подзаголовок: «Источник → тезисы → формат → публикация. На одной канве. Без
перебежек между ChatGPT, Notion и Telegram.»

**Целевая аудитория:** фаундеры, эксперты, консультанты, авторы личного
бренда — есть материал (подкасты, статьи, мысли), нет времени регулярно
делать контент.

**Ключевые ценности (блоки-фичи):**
1. **Один источник → десятки идей.** Грузишь подкаст, статью или транскрипт —
   ИИ извлекает тезисы и ранжирует по виральности.
2. **Твой голос, не ИИ-стиль.** Обучается на твоих прошлых постах. Манифест,
   табу, маркеры — ИИ знает, что и как ты пишешь.
3. **Все платформы за раз.** Telegram, LinkedIn, Instagram, X, статья,
   карусели — каждая со своими механиками.
4. **Визуальный канвас.** Весь путь от идеи до публикации на одной доске, а не
   в десяти вкладках.
5. **AI-ассистент прямо на полотне.** Обсуждаешь и дорабатываешь материал в
   чате, подключив нужные ноды.
6. **Публикация из окна.** Telegram напрямую, контент-план и календарь.

**Структура страницы (рекомендуемая):**
1. Hero: заголовок + подзаголовок + CTA «Попробовать бесплатно» +
   визуал канваса.
2. Проблема → решение (3 строки «до/после»).
3. Как это работает: 3–4 шага (Источник → Извлечение → Формат → Публикация).
4. Сетка фич (6 блоков выше).
5. Демонстрация: скриншот/видео канваса в работе.
6. Для кого (сегменты).
7. Тарифы (Free / Solo / Pro / Team — с пометкой «оплата скоро»).
8. Финальный CTA + футер.

**Тон и стиль:** тёмная тема, акцент — насыщенный (амбер/электрик), крупная
жирная типографика, уверенно, без корпоративного языка. RU (основной), EN
опционально.

**CTA:** «Попробовать на одном канвасе» / «Начать бесплатно» → ведёт на `/try`
(создаёт preview-сессию без регистрации).

## 8. ЧТО НЕ ВХОДИТ (осознанно отложено)
- Генерация видео с ИИ-двойником (отдельный продукт-концепт).
- Автопостинг по расписанию воркером (сейчас публикация ручная/по кнопке).
- Полноценная биллинг-интеграция (Т-Банк recurring — Phase 2).
- Мобильный редактор канваса (desktop-first; на телефоне — просмотр).
